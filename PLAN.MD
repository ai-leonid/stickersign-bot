## Цель
Создать NestJS-приложение с телеграм-ботом, который генерирует стикерпак из букв введённой фразы, упорядочивает стикеры так, чтобы в окне добавления (5x5) складывались предложения, и поддерживает пользовательскую «кнопку-стикер» (кастомное изображение) для открытия окна добавления.

## Псевдокод (детально)
1. Получить входное событие от Telegram:
   - определить команду пользователя
   - извлечь текст фразы
   - при наличии извлечь пользовательское изображение
2. Верифицировать вход:
   - проверить длину и допустимые символы
   - проверить лимиты на создание/обновление наборов
   - при ошибке вернуть понятное сообщение
3. Нормализовать текст:
   - привести повторяющиеся пробелы к одному
   - сохранить переносы строк
   - обрезать до максимального размера сетки
4. Преобразовать текст в матрицу 5x5:
   - разбить на строки по переносам
   - заполнить по строкам слева направо
   - пустые ячейки отметить как пустые
5. Подготовить параметры визуального стиля:
   - выбрать шрифт, кегль, цвет, обводку
   - определить фон, отступы и центрирование
6. Сгенерировать изображения:
   - для каждой буквы создать квадратный холст
   - отрисовать букву по центру
   - сохранить в формате, совместимом с Telegram
7. Создать или обновить стикерпак:
   - если набора нет, создать новый
   - если есть, обновить порядок первых 25 стикеров
   - заполнить пустые позиции «пустыми» стикерами
8. Обработать пользовательскую «кнопку-стикер»:
   - провалидировать изображение
   - добавить как отдельный стикер или отдельный набор
9. Сохранить метаданные:
   - пользователь, набор, список букв, порядок, файлы
10. Вернуть результат пользователю:
    - ссылка на набор
    - краткие инструкции по использованию
