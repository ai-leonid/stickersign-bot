# TG Sign Sticker Bot

Телеграм-бот на NestJS, который создаёт стикерпак из букв введённой фразы. Первые 25 стикеров формируются так, чтобы в окне добавления стикеров (5x5) складывалось предложение. Поддерживается пользовательская «кнопка-стикер» для открытия окна добавления.

## Возможности
- /create <фраза> — создать новый набор
- /update <фраза> — обновить первые 25 стикеров
- /button — добавить кастомную кнопку-стикер
- Поддержка пробелов и переносов строк
- Заполнение пустых ячеек «пустыми» стикерами

## Требования
- Node.js 20+
- Docker (для PostgreSQL и Redis)
- Токен и username Telegram-бота

## Переменные окружения
Все переменные уже должны быть заданы в .env. Используются:
- TELEGRAM_BOT_TOKEN
- TELEGRAM_BOT_NAME
- DATABASE_URL
- STORAGE_PATH
- REDIS_URL
- S3_ENDPOINT
- S3_BUCKET
- S3_REGION
- S3_ACCESS_KEY
- S3_SECRET_KEY

## Локальный запуск
1. Установить зависимости:

```bash
npm install
```

2. Поднять сервисы PostgreSQL и Redis:

```bash
docker compose up -d
```

3. Запустить бота в режиме разработки:

```bash
npm run start:dev
```

Бот работает через long polling, публичный URL не нужен.

## Производственный запуск
1. Собрать проект:

```bash
npm run build
```

2. Запустить:

```bash
npm run start:prod
```

## Использование бота
1. Откройте бота в Telegram и отправьте /start.
2. Создайте набор:

```text
/create Привет мир
```

3. Обновите существующий набор:

```text
/update Новый текст
```

4. Добавьте кастомную «кнопку-стикер»:
   - Отправьте /button
   - Пришлите PNG или WebP как файл (без сжатия)
   - Прозрачность обязательна

## Ограничения Telegram
- Только статические стикеры
- Формат: PNG или WebP с прозрачностью
- Максимальный размер файла: 512 KB
- Размер: 512x512 или одна сторона 512 px
- Лимит: до 120 стикеров в наборе

## Как формируется сетка 5x5
- Unicode NFC для стабильного рендера
- Табуляции → пробелы, повторные пробелы схлопываются
- Переносы строк сохраняются
- Заполнение по строкам слева направо
- Пустые ячейки → «пустой» стикер
