# Требования

## Функциональные
- Команды бота для создания стикерпака из текста
- Генерация по одному стикеру на каждую букву
- Размещение первых 25 стикеров в порядке, формирующем сетку 5x5
- Поддержка пробелов и переноса строк в тексте
- Добавление пользовательской картинки как «кнопка-стикера»
- Повторное создание/обновление набора при изменении фразы

## Нефункциональные
- Высокая читаемость букв на разных устройствах
- Устойчивость к ошибкам Telegram API и сетевым сбоям
- Масштабируемость хранения изображений
- Минимизация времени генерации набора
- Предсказуемость порядка стикеров при любых входных данных

## Ограничения Telegram
- Поддерживаются только статические стикеры
- Формат: PNG или WebP с прозрачностью
- Максимальный размер файла: 512 KB
- Размеры: одна сторона ровно 512 px, вторая от 1 до 512 px
- Лимит статического набора: до 120 стикеров

## Нормализация текста и лимиты
- Применяется Unicode NFC
- Последовательные пробелы схлопываются в один
- Переносы строк сохраняются
- Табуляции заменяются на пробелы
- В сетку 5x5 попадает не более 25 ячеек

## Недостаток символов для сетки 5x5
- Пустые ячейки заполняются «пустым» стикером
- Пробелы считаются пустыми ячейками

## Технологические
- Backend: NestJS 11, TypeScript
- Telegram: grammy
- База данных: PostgreSQL + Prisma ORM
- Очереди: bullmq + ioredis
- Генерация изображений: @napi-rs/canvas, sharp
