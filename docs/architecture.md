# Архитектура

## Модули NestJS
- BotModule: обработка апдейтов Telegram, маршрутизация команд
- StickersModule: генерация буквенных стикеров и управление порядком
- PacksModule: создание/обновление стикерпаков и их метаданных
- MediaModule: хранение и доступ к сгенерированным изображениям
- UsersModule: учет пользователей и их наборов
- JobsModule: очередь задач генерации и ретраи

## Инфраструктурные компоненты
- Telegram Bot API: прямые HTTP вызовы
- StorageAdapter: локальное FS, опционально S3
- QueueAdapter: bullmq + ioredis
- LoggerAdapter: pino + nestjs-pino

## Границы ответственности
- BotModule не содержит бизнес-логики, только транспорт и валидаторы ввода
- StickersModule отвечает за преобразование текста в изображения
- PacksModule отвечает за операции с Telegram API и набором
- MediaModule управляет файлами, кэшем и версиями ресурсов
- JobsModule снижает нагрузку и ускоряет ответы бота

## Внешние зависимости
- Telegram Bot API для создания и обновления стикерпаков
- Хранилище файлов для стикеров и пользовательских изображений
- PostgreSQL для метаданных и связей через Prisma
