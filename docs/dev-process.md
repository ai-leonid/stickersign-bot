# Методология разработки

## Принципы
- KISS и SOLID для модульной и читаемой архитектуры
- Максимальная повторная используемость кода генерации
- Строгая типизация и отсутствие any

## Подход к изменениям
- Маленькие изолированные коммиты
- Контроль качества через линтер и тесты
- Документация обновляется вместе с кодом
