# Пользовательские сценарии

## Создание стикерпака
1. Пользователь отправляет команду создания набора и фразу
2. Бот подтверждает параметры и запускает генерацию
3. Бот сообщает, что набор готов, и отправляет ссылку

## Обновление набора
1. Пользователь отправляет новую фразу
2. Бот пересоздаёт порядок первых 25 стикеров
3. Бот сообщает об успешном обновлении

## Кастомная «кнопка-стикер»
1. Пользователь отправляет /button
2. Бот просит PNG/WebP с прозрачностью как файл
3. Пользователь отправляет изображение файлом
4. Бот валидирует формат и добавляет изображение в набор
